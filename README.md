# ESPHome Component for Grundfos ALPHA3 (GENI over BLE)

[![ESPHome](https://img.shields.io/badge/ESPHome-Component-blue?logo=esphome)](https://esphome.io/)
[![Home Assistant](https://img.shields.io/badge/Home%20Assistant-Ready-41BDF5?logo=home-assistant)](https://www.home-assistant.io/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

[Wersja polska (README.pl.md)](./README.pl.md)

A complete **ESPHome** custom component for **ESP32** (and **ESP32-C3**) microcontrollers that enables real-time telemetry monitoring and wireless control of **Grundfos ALPHA3** circulation pumps (and compatible Grundfos pumps with Bluetooth connectivity) directly in **Home Assistant**.

This integration reverse-engineers the proprietary **GENI (GENIbus / GENIpro over BLE)** protocol and the BLE SMP (Security Manager Protocol) authentication flow used by the official **Grundfos GO Remote** mobile application.

---

## ✨ Features

### 1. Live Telemetry & Sensors
- **Active Power ($W$)**: Real-time electrical power consumption (matching pump display & app 1:1).
- **Rotor Speed ($RPM$)**: Actual motor shaft rotational speed.
- **Estimated Flow ($m^3/h$)**: Instantaneous water flow rate.
- **Head / Pressure Difference ($m$)**: Real-time hydraulic head generated by the pump.
- **Current Setpoint ($m$)**: Target head setpoint (user-configured or dynamically calculated by AutoAdapt).
- **Total Energy Counter ($kWh$)**: Cumulative electricity consumption since the pump was first commissioned.
- **Mains Voltage ($V$)**: Real-time grid AC supply voltage.
- **Motor Current ($A$)**: Current draw through the motor windings.
- **Shaft Mechanical Power ($W$)**: Mechanical power delivered to the pump impeller.
- **Temperatures ($^\circ C$)**:
  - Control module / Inverter electronics temperature
  - Motor windings temperature
  - Estimated pumped water / liquid temperature
- **Motor Running State (`binary_sensor`)**: Indicates whether the pump is actively circulating fluid.
- **BLE Bonded State (`binary_sensor`)**: Confirms secure, encrypted connection (BONDED in ESP32 NVS).

### 2. Full Wireless Control
- **Power Switch (`switch`)**:
  - `ON` $\rightarrow$ Normal operation
  - `OFF` $\rightarrow$ Immediate pump stop
- **Operating Mode Select (`select`)**:
  - `Normal`: Standard operation according to the selected control mode
  - `Stop`: Pause pump operation
  - `Min`: Force operation on the minimum curve
  - `Max`: Force maximum speed/curve (ideal for air purging or rapid warm-up)
- **Control Mode Select (`select`)**:
  - `AutoAdapt`: Autonomous dynamic adjustment to heating load
  - `Proportional Pressure`: Recommended for two-pipe radiator systems with thermostatic valves
  - `Constant Pressure`: Recommended for underfloor heating systems
  - `Constant Curve`: Fixed speed operation (curves I, II, III)
  - `Radiator Mode`
  - `Underfloor Mode`
  - `Combined Mode` (Radiator + Underfloor)
- **Head Setpoint Adjustment (`number`)**:
  - Precision slider in Home Assistant from **1.0 m** to **6.0 m** (0.1 m increments).
- **Pairing Control Buttons (`button`)**:
  - `Pair Pump`: Triggers SMP encryption request (used during initial physical button confirmation).
  - `Unpair Pump`: Clears the stored BLE bond from ESP32 NVS memory.

### 3. Diagnostics & Alarms
- **Alarm Code (`sensor`)**: Raw error/alarm status register from the pump (`0` = Normal / OK).
- **Alarm Description (`text_sensor`)**: Human-readable error description (e.g., *Dry running*, *Blocked rotor*, *Undervoltage*).
- **Device Name (`text_sensor`)**: Custom device name stored in the pump (e.g., "HEATING").

## 🔐 How BLE SMP Pairing & Security Works

Grundfos ALPHA3 pumps implement **Bluetooth Low Energy Security Manager Protocol (BLE SMP)** with **physical button push-to-pair verification** to prevent unauthorized access:

```
[ ESP32 ]                                    [ Grundfos ALPHA3 ]
    |                                                 |
    |---- 1. BLE Connect (Pump MAC Address) --------->|
    |---- 2. BLE SMP Pair Request (Just Works) ------>|
    |                                                 |
    |   [Pump LED starts blinking]                    |
    |   >>> PRESS PHYSICAL RADIO BUTTON ON PUMP! <<<  |
    |                                                 |
    |            *** Physical Button Pressed ***      |
    |                                                 |
    |<--- 3. SMP Key Exchange & Encryption Done ------|
    |                                                 |
    |== Keys permanently saved in ESP32 NVS Flash! ==|
    |                                                 |
    |<=== 4. Encrypted GENIbus Telemetry Streaming ==|
```

> [!NOTE]
> **One-time physical pairing**: Once paired and bonded, the cryptographic encryption keys are stored persistently in ESP32 NVS memory. The pump will reconnect automatically upon reboots without ever requiring you to touch the physical button again.

## 🛠️ Hardware Requirements

Any ESP32 development board with Bluetooth Low Energy (BLE) support:
- **Standard ESP32** (ESP-WROOM-32, NodeMCU ESP32, DevKit V1)
- **ESP32-C3** (SuperMini C3, Seeed Studio Xiao ESP32C3) - *compact, power-efficient, highly recommended!*
- **ESP32-S3**

### Recommended Board Settings:

```yaml
# Standard ESP32:
esp32:
  board: esp32dev
  framework:
    type: arduino

# ESP32-C3:
esp32:
  board: esp32-c3-devkitm-1
  variant: esp32c3
  framework:
    type: arduino
```

## 🚀 Quick Start Guide

### Step 1: Discover Your Pump's BLE MAC Address

`grundfos_alpha3_esp32.yaml` includes an automatic BLE scanner:

1. Flash your ESP32 with `grundfos_alpha3_esp32.yaml` (you can leave the placeholder MAC address `B4:E6:2D:XX:XX:XX`).
2. Open the **ESPHome Web Log Viewer** or connect via Serial Monitor.
3. Walk up to your ALPHA3 pump and briefly press the connectivity/radio button on the front panel.
4. The scanner will output a highlighted message with your pump's exact MAC address:
   ```text
   [I][alpha3_scanner]: ============================================================
   [I][alpha3_scanner]: >>> ZNALEZIONO POMPĘ GRUNDFOS W ZASIĘGU BLE! <<<
   [I][alpha3_scanner]:   Nazwa rozgłaszana: 'Grundfos ALPHA3'
   [I][alpha3_scanner]:   Adres MAC pompy:   00:81:F9:XX:XX:XX
   [I][alpha3_scanner]:   Siła sygnału RSSI: -58 dBm
   [I][alpha3_scanner]: Wpisz powyższy adres MAC do konfiguracji YAML jako pump_mac_address!
   [I][alpha3_scanner]: ============================================================
   ```
5. Copy this MAC address.

### Step 2: Configure Wi-Fi and Pump MAC Address

In `grundfos_alpha3_esp32.yaml`, update the substitutions and Wi-Fi credentials:

```yaml
substitutions:
  name: "grundfos-alpha3-controller"
  friendly_name: "Pompa Grundfos ALPHA3"
  pump_mac_address: "00:81:F9:XX:XX:XX"  # Your pump's real MAC address

wifi:
  ssid: "YOUR_WIFI_SSID"
  password: "YOUR_WIFI_PASSWORD"
```

### Step 3: Flash and Perform Initial Pairing

1. Click **Install** in ESPHome Dashboard (or run `esphome run grundfos_alpha3_esp32.yaml`).
2. Watch the logs. When the ESP32 initiates connection:
   ```text
   [W][grundfos_alpha3]: >>> NACIŚNIJ TERAZ PRZYCISK POŁĄCZENIA (RADIA) NA POMPIE! <<<
   ```
3. **Press the physical connect button on the ALPHA3 pump**.
4. The logs will confirm successful pairing and key bonding:
   ```text
   [I][grundfos_alpha3]: SUKCES! Pompa Grundfos ALPHA3 sparowana i połączenie zaszyfrowane!
   ```
5. All telemetry sensors, switches, and sliders will instantly populate in Home Assistant!

## 📦 Using as an External Component in Existing YAML

If you want to incorporate this component into your existing ESPHome configuration:

```yaml
external_components:
  - source: github://Seba65439/esphome-grundfos-alpha3
    components: [ grundfos_alpha3 ]

esp32_ble:
  io_capability: none

esp32_ble_tracker:
  scan_parameters:
    interval: 1100ms
    window: 300ms
    active: false

ble_client:
  - mac_address: "00:81:F9:XX:XX:XX"
    id: alpha3_ble
    auto_connect: true
    on_numeric_comparison_request:
      - then:
          - ble_client.numeric_comparison_reply:
              id: alpha3_ble
              accept: true
    on_passkey_request:
      - then:
          - ble_client.passkey_reply:
              id: alpha3_ble
              passkey: 0

grundfos_alpha3:
  id: pump_alpha3
  ble_client_id: alpha3_ble
  update_interval: 10s
```

## 📊 Home Assistant Lovelace Dashboard

A complete, native Home Assistant Lovelace dashboard is provided in [`home_assistant_dashboard.yaml`](./home_assistant_dashboard.yaml).

### Dashboard Highlights:
- **Big Gauge Dials**: Real-time Head ($m$, up to 5.0m), Flow Rate ($m^3/h$), and Active Power ($W$) with severity color coding.
- **Secondary Gauges**: Water temperature, motor RPM, and impeller shaft power.
- **Control Station**: Main power toggle, operating mode picker (Normal / Min / Max / Stop), control mode picker (AutoAdapt / Constant Pressure / Proportional Pressure), and setpoint slider.
- **Electrical Diagnostics**: Voltage ($V$), Current ($A$), Total Energy Meter ($kWh$), and PCB electronics temperatures.
- **Smart Conditional Alarm Banner**: Automatically appears in vibrant red whenever a pump error or alarm is triggered.
- **12-Hour Telemetry Graph**: Real-time historical chart of power, flow, and head over time.

### How to Import:
1. Open your Home Assistant Dashboard.
2. Click the pencil icon (Edit Dashboard) in the top-right corner.
3. Click the `+` icon to **Add View** (new tab).
4. Click the three dots `⋮` in the dialog header $\rightarrow$ **Edit in YAML**.
5. Paste the entire content of [`home_assistant_dashboard.yaml`](./home_assistant_dashboard.yaml) and click **Save**.

## 🔬 Protocol & Technical Notes

- **Communication Layer**: Bluetooth Low Energy (GATT).
- **Service UUID**: `859cffe0-036e-432a-aa28-1a0085b87ba9`
- **Write Characteristic (TX)**: `859cffe1-036e-432a-aa28-1a0085b87ba9` (Client $\rightarrow$ Pump)
- **Notification Characteristic (RX)**: `859cffe2-036e-432a-aa28-1a0085b87ba9` (Pump $\rightarrow$ Client)
- **Protocol Framing**: GENIbus / GENIpro packets framed with delimiter `0x24` (`$`), packet length, destination/source addresses, class ID, data ID, parameters, and 8-bit checksum.
- **Data IDs decoded**:
  - Class `0x09` (Parameters & Setpoint)
  - Class `0x0A` (Telemetry: Power, Flow, Head, RPM, Voltage, Current, Temperatures)
  - Class `0x04` & `0x08` (Alarms, Warnings & Operational State)
